<h2>Vector</h2>

A vector in C++ is like a resizable array.<br>
Both vectors and arrays are data structures used to store multiple elements of the same data type. <br>
The difference between an array and a vector, is that the size of an array cannot be modified (cannot add or remove elements from an array). However, vector has the ability to resize itself automatically when an element is inserted or deleted.

<h3>Create a Vector</h3>

To create a `vector`, use the vector keyword, and specify the **type** of values it should store within angle brackets `<>` and then the name of the vector, like: `vector<type> vectorName` <br>
